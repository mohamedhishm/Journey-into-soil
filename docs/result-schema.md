# Result contract
`contracts/result.schema.json` (v1.1.0). `contracts/mock_result.json` is generated by `make mock` from the real engine. Messages are `{key, params}`; catalogs in `contracts/i18n/{en,ar}.json`. `sim.crop_idx` indexes the strategy's non-fallow seasons, -1 when bare.

## Changes in 1.1.0
- Added `strategy.uncertainty`: empirical distributions ($p10, p50, p90$) for `irrigation_mm`, `water_stress`, `salinity_stress`, `heat_days`, and `total_score` across $N$ historical weather years (default 2011–2025 from NASA POWER pack).
- Added `strategy.uncertainty.rank_stability`: fraction of historical years in which the strategy retains its baseline rank in the candidate pool.
- Added `conf.high_climate_variance` factor in `confidence` when score spread $(p90 - p10) \ge 0.20$ or rank stability $< 0.60$.
