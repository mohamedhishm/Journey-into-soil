# Arabic Translation Review & Terminology Reference (B14)

Prepared for Egyptian agronomist / native speaker review pass.
Key agricultural terminology adapted for Egyptian farming context and NASA Space Apps 2026.

## Key Improvements Applied
- Coarse Resolution: Refined satellite terminology from literal coarse to approximate / broad-scale spatial resolution.
- Paddy / Rice Ponding: Clarified that rice continuous flooding (ghamr) is not modelled.
- Legume Biological Fixation: Clarified nodulation and biological nitrogen fixation phrasing.
- Salinity / Water EC: Clarified Egyptian agronomy units and soil salinity phrasing.
- Interactive Sharing & Demo Sites: Native Arabic microcopy for one-click demo sites and link sharing.
