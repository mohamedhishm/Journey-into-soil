# Windows Bootstrap Support Plan

**Date:** 2026-11-05  
**Topic:** Windows Bootstrap Support (`scripts/bootstrap.ps1`, `scripts/sync_contract.ps1`, `scripts/bootstrap.bat`, `scripts/bootstrap.sh`)

## Context & Objectives
The repository setup previously provided a single bash script (`scripts/bootstrap.sh`) geared toward POSIX systems (Linux, macOS, WSL). On native Windows systems, developers encounter:
1. Lack of native bash execution in PowerShell / Command Prompt.
2. Differences in virtual environment structure (`.venv\Scripts\` instead of `.venv/bin/`).
3. Discrepancies in default Python executable names (`python` vs `python3`) and POSIX paths generated by tools like Git Bash (`/c/Users/...`), which break Python's `pathlib.Path` and SQLite URI handling on Windows.

The objective is to provide a first-class developer bootstrap experience on Windows via native PowerShell and CMD, while maintaining complete backward compatibility with POSIX environments and hardening `scripts/bootstrap.sh` for Git Bash on Windows.

## Proposed Changes
1. **[scripts/bootstrap.ps1](../../scripts/bootstrap.ps1)**
   - Check required tools (`python` or `py`/`python3`, `node`, `npm`, optional `docker`).
   - Copy `.env.example` to `.env` if not present.
   - Append Windows-friendly environment overrides with normalized forward slashes for SQLite (`sqlite:///<repo-root>/data/app.db`) and paths.
   - Create `.venv` using `python -m venv .venv`.
   - Use `.venv\Scripts\python.exe` and `.venv\Scripts\pip.exe` directly to bypass execution policy restrictions.
   - Upgrade pip and install API and pipeline dependencies.
   - Run `python scripts/make_mock_result.py`.
   - Sync contract files using PowerShell file operations.
   - Run API tests (`pytest`) and web typechecking (`npm run typecheck`).
   - Print clear next-step instructions.

2. **[scripts/sync_contract.ps1](../../scripts/sync_contract.ps1)**
   - Standalone PowerShell script to sync contract mock results and i18n catalogs to `web/`.

3. **[scripts/bootstrap.bat](../../scripts/bootstrap.bat)**
   - CMD/batch convenience wrapper invoking PowerShell with `-ExecutionPolicy Bypass`.

4. **[scripts/bootstrap.sh](../../scripts/bootstrap.sh)**
   - Add Windows/MSYS/Cygwin detection.
   - Allow fallback to `python` if `python3` is not found.
   - Activate `.venv/Scripts/activate` when on Windows instead of `.venv/bin/activate`.
   - Normalize Windows paths when writing `.env` under MSYS/Git Bash (`pwd -W`).

5. **Documentation**
   - Update [README.md](../../README.md) and [AGENTS.md](../../AGENTS.md) with Windows bootstrap commands.

## Verification
- Run `powershell -ExecutionPolicy Bypass -File scripts/bootstrap.ps1` end-to-end.
- Ensure API tests pass (`pytest -q` in `api/`).
- Ensure linter passes (`ruff check .` in `api/`).
- Ensure web typecheck and build pass (`npm run typecheck` and `npm run build` in `web/`).
- Ensure i18n parity check passes (`python scripts/check_i18n.py`).
- Validate contract schema (`api/tests/test_contract.py`).
